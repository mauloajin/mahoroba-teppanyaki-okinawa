# mahoroba 鉄板 沖縄-Teppanyaki Steak&Wine Bar

那覇市松山の店舗専用ウェブサイトです。Next.jsで静的出力し、Vercelで公開します。

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

静的生成物は `out/` に出力されます。
